Installation Instructions

Windows (.exe)

Download the .exe file and double-click to run. No additional setup required.

macOS (.dmg)

Download the .dmg file and drag the app to your Applications folder. Requires macOS 10.15 or higher.

Linux (.deb)

For Debian/Ubuntu, download the .deb file and install with:

sudo dpkg -i TypeOfWar.deb

Universal (.jar)

Your OS wasn't listed here? Play anyway! Run the .jar file (requires JDK 21+):

java -jar TypeOfWar.jar
